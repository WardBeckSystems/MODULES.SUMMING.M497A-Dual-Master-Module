The transformers should be close to the same if not identical... for all i know the line amps may have a few resistors that can be cut and voila a mic pre-amp. do some digging and get back to the group. WBS used a lot of the same components thought everything. ie: M477 is the same PCB as an M473, M473A and M497A, B and C... M470, A, C, D, E, same PCB, the pre-amp in the M470 is the same as the M490s. kinda fun to know :-) they re-used a lot of designs to keep production costs down.
